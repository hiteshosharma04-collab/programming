pass by value vs pass by refrence 

* pass by value : A copy of the actual value is passed to the function.
chnges made to the parameter inside the function do not affect the acutal variable

*pass by refrences: The memory address of the variable is passed to the function.
changes made inside the function will directly affect the actual value
